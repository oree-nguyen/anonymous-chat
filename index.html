HONEST LIMITS

Private is not invisible.

This experimental tool reduces stored data. It does not solve every threat.

IP addresses can be visible

Direct WebRTC reveals peer IP addresses and contacts Google's STUN service while connecting.

No independent audit

Do not substitute this project for a mature audited messenger in high-risk situations.

Your device still matters

Malware, screenshots, copied text, and an unlocked screen remain outside this app's control.
